브라우저만으로 올리는 방법
  1. GitHub 저장소에서 Add file을 누른다.
  2. Create new file을 고른다.
  3. 파일 이름을 log.md로 만든다. 이미 있으면 파일을 열고 연필 아이콘을 누른다.
  4. 위에서 만든 Markdown을 맨 아래에 이어 붙인다.
  5. 아래 초록색 Commit changes 버튼을 누른다.
