오늘의 목표

Markdown 문법을 몰라도 프로젝트 일지 1개를 만들고 GitHub에 올릴 준비를 끝낸다.

처음 배우는 학생용

일지는 보고서가 아니라, 오늘의 작업 증거입니다.

좋은 프로젝트 일지는 완벽한 글보다 “무엇을 시도했고, 무엇이 막혔고, 다음에 무엇을 할지”가 분명한 글입니다. 아래 질문에 짧게 답하면 GitHub README나 `docs/journal/`에 붙여 넣을 수 있는 Markdown이 자동으로 만들어집니다.

# 2026-05-22 프로젝트 일지

## 오늘 한 일
- 센서 값을 읽었다.
- 오류를 기록했다.

## 다음 할 일
- 그래프를 추가한다.

필수 폴더 구조
처음 저장소는 이렇게 시작
my-project/
├─ README.md
├─ docs/
│  └─ journal/
│     ├─ 2026-05-22.md
│     └─ 2026-05-29.md
├─ src/
└─ images/
`README.md`에는 프로젝트 소개를 쓰고, 매일/매주 일지는 `docs/journal/날짜.md`에 모은다. 사진은 `images/`에 넣고 일지에서 연결한다.

          
Markdown 최소 문법
이 6개만 알면 충분
  • # 제목가장 큰 제목
  • ## 소제목내용 구역 나누기
  • - 항목목록 만들기
  • **강조**중요한 말 굵게
  • `코드`명령어, 파일명 표시
  • ![설명](이미지주소)사진 넣기

        

        
GitHub 업로드 순서
브라우저만으로 올리는 방법
  1. GitHub 저장소에서 Add file을 누른다.
  2. Create new file을 고른다.
  3. 파일 이름에 docs/journal/2026-05-22.md처럼 입력한다.
  4. 위에서 만든 Markdown을 붙여 넣는다.
  5. 아래 초록색 Commit changes 버튼을 누른다.
